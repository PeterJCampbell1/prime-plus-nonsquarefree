# prime-plus-nonsquarefree
Computational verification for the sum of a prime and a non-square-free number.

## Runtime benchmark

`compute_M_values.py` completed in 1117.450 seconds
(approximately 18 minutes 37 seconds) on:

- **CPU:** AMD Ryzen 5 5600X
- **Execution:** single-threaded
- **OS:** Windows 11, 64-bit
- **Python:** 3.14.5

## Output

The complete outputs produced by the programs used for version 1 of the paper are included in the `output/` directory.

- `output/compute_M_values.csv`
- `output/finite_verification.txt`
